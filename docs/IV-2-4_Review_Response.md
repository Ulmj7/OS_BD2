# IV-2-4 · Шүүмжийн хариу

F.CSM302 Үйлдлийн систем · Бие даалт 2 · Kernel Data Structures

Эх сурвалж: **A** — II-4-1 Шүүмж (22 х.), **B** — II-4-1 Review (9 х.), **C** — IV-2-1 Review (11 х.), **D** — IV-2-7 Review (11 х.). Шүүмжүүд өмнөх Report, Manual болон түүнд харгалзах кодыг үнэлсэн. Доорх лавлагаа нь шинэчилсэн тайлан, гарын авлага ба кодыг заана. Албан ёсны репозиторийн `main` салбарыг [GitHub-ээс](https://github.com/Ulmj7/OS_BD2) татна.

## Эцсийн хувилбарын шалгалт

- ASan + UBSan: 4 C багц, 9 сценарийн 229 хариу, 15 HTTP тест амжилттай. Үндсэн багц 5/5, HTTP багц 30/30 давталтаар амжилттай. Үр дүнг тайлангийн 8.1, гарын авлагын 8.2.8-аас үзнэ.
- 2026-11-25-нд Arch Linux 7.3.4-arch1-2 x86_64 дээр хоёр шинэ `.ko` хөрвүүлж, тус бүрийг хоёр удаа амжилттай ачаалж зайлуулсан. `dmesg`-д өнгөний 4 мөр ба `color_list: freed 4 nodes`, Collatz 27-ийн 112 утга (оргил 9232, индекс 77) ба `collatz: freed 112 nodes` хоёр удаа ижил гарсан (тайлан 8.8, гарын авлага 8.2.7). Анхдагч 25, буруу 0-ийг шинэ хувилбараар давтаагүй.
- Headless Brave 158 дээр `abc` хаагдаж, `-5`, `+7`, `42` зөвшөөрөгдсөн. «Бүгдийг багтаах» ба End нь 112 зангилааг desktop болон 390 px өргөнд 25% буюу түүнээс том масштабаар багтаасан. 320/390 px өргөнд хэвтээ халилт гараагүй. Шинэ зургууд [Collatz-ийн бүтэн граф](img/08_peer_review_collatz_fit_all.png), [Stack-ийн тоон оролт](img/09_peer_review_stack_pattern.png). Өмнөх зургуудын «Ашигласан байт» шошго одоо «Хүссэн байт» болсон.

## Teams-ийн үндсэн постод хариулах текст

> II-4-1, IV-2-1, IV-2-7 багуудад бие даан туршиж, саналаа өгсөнд баярлалаа. Репозиторийн хаяг, тайлан, гарын авлагыг нэг мөр болголоо. HTTP-ийн хэт том хүсэлт, гадаад Host, IPv6-гүй орчин, зэрэгцээ холболтын асуудлыг засаж, тест нэмсэн. ASan + UBSan шалгалтаар 4 C багц, 9 сценарийн 229 хариу, 15 HTTP тест амжилттай. Chromium-ийн тоон оролтыг засаж, урт графт «Бүгдийг багтаах» товч, Collatz дүрмийн тайлбар, «Хүссэн байт» шошго нэмсэн.
>
> Тайлангийн 8.8–8.9-д Arch, Ubuntu, Xubuntu дээр өмнөх модулиудыг ачаалсан нотолгоо, IV-2-7-ийн зөвхөн хөрвүүлсэн үр дүнг оруулсан. 2026-11-25-нд шинэ хоёр модулийг Arch Linux 7.3.4-arch1-2 дээр хоёр удаа ачаалж, алдаагүй зайлуулсан. Өнгөний 4 мөрийн дараа `color_list: freed 4 nodes`, Collatz 27-ийн 112 мөрийн (оргил 9232, индекс 77) дараа `collatz: freed 112 nodes` хоёр удаа ижил гарсан. Шинэ хувилбарын анхдагч 25, буруу 0, бодит кернелийн ENOMEM, kmemleak/slabinfo, 200 удаагийн давталт үлдсэн. Зангилаа хураах горим, сесс тус бүрийн тоолуур, гишүүдийн тусдаа commit болон шинэ Tag/Release хийгдээгүй.
>
> Шинэчилсэн тайлан, гарын авлагыг энэ хариунд хавсаргав. Репозиторийн `main` салбар: https://github.com/Ulmj7/OS_BD2. Шүүмж бүрийн хариу: `docs/IV-2-4_Review_Response.md`.
